# ♻️ Geri Dönüşüm Projesi

Geri Dönüşüm Projesi, geri dönüşüm bilincini artırmayı ve kullanıcıları çevre dostu davranışlara teşvik etmeyi amaçlayan bir uygulamadır.

## ✨ Özellikler

- Geri dönüşüm süreçlerini destekleyen kullanıcı dostu arayüz
- Çevre bilincini artırmaya yönelik özellikler
- Kullanıcı etkileşimini destekleyen modern tasarım

## 🛠️ Kullanılan Teknolojiler

- React
- TypeScript
- Node.js
- Express.js
- Tailwind CSS
- PostgreSQL

## 🚀 Kurulum

Projeyi bilgisayarınıza klonlayın:

```bash
git clone https://github.com/nisadik/Geri-Donusum-Projesi.git
```

## Proje klasörüne girin:
```bash
cd Geri-Donusum-Projesi
```

## Bağımlılıkları yükleyin:
```bash
npm install
```

## Projeyi çalıştırın:
```bash
npm run dev
```
